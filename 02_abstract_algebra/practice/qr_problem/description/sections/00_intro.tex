\section*{Problem 0: Start the Engine}

Welcome to the Abstract Algebra Laboratory on Reed--Solomon Codes. In this laboratory, we will explore the profound power of Python's \textbf{Duck Typing} and polymorphic objects to build a fully functional QR code error-correction system from first principles.

We will build a single, universal \lstinline|Polynomial| class that performs algebra using standard operators (\lstinline|+|, \lstinline|-|, \lstinline|*|, \lstinline|/|). Because it does not care \textit{what} type of objects it is operating on, we can feed it integers modulo $p$ (for $GF(p)$ math) \textit{or} elements of our extension field (for $GF(p^n)$ math).
