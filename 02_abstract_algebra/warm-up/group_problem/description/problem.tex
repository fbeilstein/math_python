\subsubsection*{Group Engine API Reference}
You will be provided with helper classes \lstinline|Group| and \lstinline|GroupElement| to interact with the algebraic structures. Before diving into the implementations, you must understand how to use them:

\textbf{The \lstinline|GroupElement| Object}\\
Elements of a group are represented as abstract objects. You do not need to know their internal mathematical representation. You only need to use the overloaded Python operators:
\begin{itemize}
    \item \textbf{Multiplication:} \lstinline|a * b| returns a new \lstinline|GroupElement| representing $a \cdot b$.
    \item \textbf{Inversion:} \lstinline|~a| returns a new \lstinline|GroupElement| representing $a^{-1}$.
    \item \textbf{Equality:} \lstinline|a == b| returns \lstinline|True| if the elements are identical.
\end{itemize}
\textit{Note: \lstinline|GroupElement| objects are fully hashable and can be safely used as keys in dictionaries or stored in sets.}

\textbf{The \lstinline|Group| Object}\\
The \lstinline|Group| object represents a mathematical group (or subgroup). It acts like a Python container:
\begin{itemize}
    \item \textbf{Iteration:} \lstinline|for g in group:| iterates over all elements in the group.
    \item \textbf{Membership:} \lstinline|g in group| returns \lstinline|True| if the element $g$ is in the group.
    \item \textbf{Identity:} \lstinline|group.identity_element| returns the identity $e \in G$.
    \item \textbf{Elements:} \lstinline|group.elements| returns a raw Python list of all elements.
\end{itemize}

\textbf{Constructing Subgroups dynamically:}\\
When algorithms (like \lstinline|generate_group|) require you to build a new group from scratch, you can instantiate and populate a \lstinline|Group| object manually:
\begin{lstlisting}[language=Python]
# Create a new group starting with just the identity
H = Group(elements=[identity_element])

# Add a single element
H.add(new_element)

# Add a list of elements
H.add_elements([e1, e2, e3])
\end{lstlisting}

\section*{Problem 1: Multiplication Table Axioms (Level 1)}

\subsubsection*{Mathematical part}
\textbf{Recall:} The four fundamental axioms that define a group $(G, \cdot)$. You are expected to know these intimately. If you have forgotten, consult your textbook to review:
\begin{enumerate}
    \item \textbf{Closure:} $\forall a, b \in G, a \cdot b \in G$.
    \item \textbf{Associativity:} $\forall a, b, c \in G, (a \cdot b) \cdot c = a \cdot (b \cdot c)$.
    \item \textbf{Identity:} $\exists e \in G$ such that $\forall a \in G, e \cdot a = a \cdot e = a$.
    \item \textbf{Inverses:} $\forall a \in G, \exists a^{-1} \in G$ such that $a \cdot a^{-1} = a^{-1} \cdot a = e$.
\end{enumerate}

\subsubsection*{Implementation part}
\textbf{Task:} Implement the four foundational axiom checks. 
\textbf{Details:} In this lab, we use a pure Object-Oriented API. You must use python's overloaded multiplication operator (\lstinline|a * b|) and evaluate the following logic:
\begin{itemize}
    \item \lstinline|check_closure|: Iterate all pairs $a, b \in G$. Return false if $a \cdot b \notin G$.
    \item \lstinline|check_associativity|: Iterate all triplets $a, b, c \in G$. Return false if $(a \cdot b) \cdot c \neq a \cdot (b \cdot c)$.
    \item \lstinline|find_identity|: Find the element $e$ where $e \cdot a = a \cdot e = a$ for all $a \in G$. Return it.
    \item \lstinline|check_inverses|: Given $e$, iterate all $a \in G$ and ensure there exists some $b \in G$ where $a \cdot b = b \cdot a = e$.
\end{itemize}

\section*{Problem 2: Permutations (Level 2)}

\subsubsection*{Mathematical part}
\textbf{Recall:} The subgroup generated by a set $S$, denoted $\langle S \rangle$, is the smallest subgroup containing $S$. Recall the definition of the order of an element $g$, which is the smallest integer $k \ge 1$ such that $g^k = e$.

\subsubsection*{Implementation part}
\textbf{Task:} Implement mechanics for the \lstinline|PermutationElement| abstract subclass, and implement general order and generator functions.

\textbf{Details:} A permutation on $n$ elements is a bijective function on the set $\{0, 1, \dots, n-1\}$. In the code, a \lstinline|PermutationElement| stores this function as a tuple called \lstinline|mapping| (accessible via \lstinline|self.mapping|). The value at \lstinline|mapping[i]| represents the output of the function when given input $i$.

\begin{itemize}
    \item \lstinline|PermutationElement.__mul__|: Compose permutations $f$ and $g$ to get $f \star g$ via function composition $(f \circ g)(x) = f(g(x))$.
    \item \lstinline|PermutationElement.__invert__|: Compute the inverse function. Create a new mapping array \lstinline|inv| such that if \lstinline|self.mapping[i]| equals $j$, then \lstinline|inv[j]| must equal $i$.
    \item \lstinline|element_order|: Find an order of an element $g$.
    \item \lstinline|generate_group|: Use a set to track discovered elements. Start with the generators and iteratively apply closure ($a \cdot b$) until no new elements are found. Return the \lstinline|Group| object.
\end{itemize}

\textbf{Recall:} Left cosets $gH$ and right cosets $Hg$. Recall that a subgroup $H$ is \textbf{normal} ($H \triangleleft G$) if and only if $gH = Hg$ for all $g \in G$. Recall that cosets partition the group into disjoint subsets of equal size.

\subsubsection*{Implementation part}
\textbf{Task:} Implement left cosets, right cosets, and the normality check.
\textbf{Details:}

    \item \lstinline|compute_right_cosets|: A right coset is $Hg = \{h \cdot g \mid h \in H\}$. Construct and return the unique cosets.
    \item \lstinline|is_normal|: Check if the set of left cosets exactly equals the set of right cosets.
\end{itemize}

\section*{Problem 6: Centers, Commutators, and Conjugacy (Level 6)}

\subsubsection*{Mathematical part}
\textbf{Recall:} 
\begin{itemize}
    \item \textbf{Center} $Z(G)$: Elements that commute with everything in $G$.
    \item \textbf{Commutator Subgroup} $[G, G]$: The subgroup generated by all elements of the form $aba^{-1}b^{-1}$.
    \item \textbf{Conjugacy Classes}: The equivalence classes under the relation $a \sim g a g^{-1}$.
    \item \textbf{Centralizer} $C(a)$: Elements that commute with $a$. Recall the class equation $|Cl(a)| \cdot |C(a)| = |G|$.
\end{itemize}

\subsubsection*{Implementation part}
\textbf{Task:} Implement the structural invariants.
\textbf{Details:}
\begin{itemize}
    \item \lstinline|compute_center|: Iterate all $z \in G$ and check if $z \cdot g = g \cdot z$ for all $g \in G$.
    \item \lstinline|compute_commutator_subgroup|: Find all commutators $aba^{-1}b^{-1}$. \textbf{Warning:} commutators don't always form a subgroup directly! You must pass all discovered commutators to \lstinline|generate_group| to get the fully closed Commutator Subgroup.
    \item \lstinline|compute_conjugacy_classes|: The conjugacy class of $a$ is $\{g \cdot a \cdot g^{-1} \mid g \in G\}$. Compute this set for all $a \in G$ and return a list of the unique classes.
\end{itemize}

\section*{Problem 7: Homomorphisms and Kernels (Level 7)}

\subsubsection*{Mathematical part}
\textbf{Recall:} A group homomorphism $\phi: G \to H$ is a function satisfying $\phi(ab) = \phi(a)\phi(b)$ for all $a, b \in G$. Key consequences:
\begin{itemize}
    \item $\phi(e_G) = e_H$ (identity maps to identity).
    \item $|\phi(g)|$ divides $|g|$ for every $g \in G$ (the \textbf{order divisibility theorem}).
    \item $\ker \phi = \{g \in G \mid \phi(g) = e_H\}$ is always a normal subgroup of $G$.
    \item The \textbf{First Isomorphism Theorem} states $G / \ker \phi \cong \operatorname{im} \phi$.
\end{itemize}

\subsubsection*{Implementation part}
\textbf{Task:} Implement a constraint-propagation engine that deduces a homomorphism from a partial mapping.

\textbf{Algorithm outline for} \lstinline|deduce_homomorphism| (Full Bidirectional Constraint Solver):
\begin{enumerate}
    \item \textbf{Initialize candidates.} For each $g \in G$, build a set of candidate images $\text{poss}[g] \subseteq H$. If $g$ is already mapped by the user, $\text{poss}[g] = \{\phi(g)\}$. Otherwise, use the order divisibility theorem to pre-filter: $\text{poss}[g] = \{h \in H : |h| \mid |g| \}$.
    \item \textbf{Bidirectional Constraint Propagation.} Repeatedly scan all pairs $(a, b) \in G \times G$. Let $c = a \cdot b$. The homomorphism property requires $\phi(c) = \phi(a)\phi(b)$, which provides three mathematically equivalent structural constraints:
    \begin{itemize}
        \item Forward: $\phi(c) = \phi(a)\phi(b)$
        \item Backward to $a$: $\phi(a) = \phi(c)\phi(b)^{-1}$
        \item Backward to $b$: $\phi(b) = \phi(a)^{-1}\phi(c)$
    \end{itemize}
    For every pair, apply these constraints to tighten the candidate sets $\text{poss}[a], \text{poss}[b], \text{poss}[c]$ using set intersections. \textbf{Important Rule:} You must handle the $a = b$ case distinctly! If $a = b$, then $c = a^2$. You must directly restrict $\text{poss}[c]$ to the squares of elements in $\text{poss}[a]$, and restrict $\text{poss}[a]$ to elements whose squares exist in $\text{poss}[c]$.
    
    If any candidate set becomes empty, a contradiction has been found --- return an empty dictionary \lstinline|\{\}|. If any set shrinks, record that a change occurred and keep scanning. The algorithm reaches a fixed point when a full scan completes with zero changes.
    \item \textbf{Extract results.} Return all elements $g$ whose candidate set has been narrowed to a single value: $\{g : |\text{poss}[g]| = 1\}$.
\end{enumerate}

\textbf{Details for other functions:}
\begin{itemize}
    \item \lstinline|is_homomorphism|: Iterate all $a, b \in G$. Ensure $\phi(a \cdot b) = \phi(a) \cdot \phi(b)$. Also ensure your code gracefully handles partial mappings (returning \lstinline|False| if $a, b$ or $a \cdot b$ are missing from the dictionary).
    \item \lstinline|compute_kernel|: Collect and return all $g \in G$ where $\phi(g) = e_H$.
    \item \lstinline|compute_image|: Collect and return all $\phi(g)$ for $g \in G$.
\end{itemize}

\textbf{Testing the Bidirectional Solver:} 
To verify that your solver correctly handles global structural constraints (and not just local element orders), test the following edge case:
\begin{itemize}
    \item Load $Z_4$ as the Source ($G$) and $U(8) \cong Z_2 \times Z_2$ as the Target ($H$).
    \item Click the \textbf{"Deduce Rest"} button (or simply map the identity $0 \in Z_4$ to $1 \in U(8)$).

If this arrow does not appear, your constraint propagation is incomplete.
\end{itemize}
